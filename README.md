# WebTikets

Este projeto consiste em um **Sistema de Atendimento e Gerenciamento de Filas** desenvolvido especificamente para otimizar o fluxo de pacientes em um **laboratório médico**. O sistema foi construído utilizando **Angular** integrado ao **Ionic**, garantindo uma interface moderna, responsiva e de alta performance tanto para dispositivos web quanto mobile.

# Funcionalidades Principais

* **Emissão de Senhas:** Geração de senhas de atendimento de forma organizada (ex: Preferencial, Geral, Exames específicos).
* **Painel de Chamadas:** Interface visual e sonora para alertar os pacientes na sala de espera sobre a próxima senha e o guichê correspondente.
* **Controle de Guichês:** Módulo exclusivo para os operadores/atendentes gerenciarem o status do guichê, chamarem a próxima senha, redispararem o alerta ou transferirem o atendimento.
* **Relatórios e Métricas:** Área administrativa voltada para a análise de dados, permitindo acompanhar o tempo médio de espera, quantidade de atendimentos por guichê e horários de pico.

# Tecnologias Utilizadas

* **Angular:** Framework base para a construção da arquitetura robusta e gerenciamento de estado da aplicação.
* **Ionic Framework:** Utilizado para a criação de componentes de interface de usuário (UI) altamente responsivos, Mobile-First e com excelente usabilidade.
